# AI 知识库助手产品需求文档 (PRD)

**项目名称**：AI 知识库助手 V1.0
**目标用户**：AI 产品岗实习生、初级产品经理
**版本**：1.0
**最后更新**：2026-09-01

## 1. 项目概述

### 1.1 背景
当前 AI 产品岗求职者缺乏系统化的专业知识库，难以快速掌握 PRD 写作、RAG 架构设计、MCP 协议等核心技能。市场上现有工具（如 Notion AI、Kimi）缺乏针对产品岗的专业知识结构化能力。

### 1.2 目标
构建一个可部署的 RAG 应用，帮助 AI 产品岗学习者：
- 上传 PRD/竞品分析/行业报告等文档
- 通过自然语言提问获取专业解答
- 查看答案的引用来源和置信度

### 1.3 成功指标
| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 回答准确率 | ≥85% | 人工抽样评估 |
| 文档解析成功率 | 100% | 系统日志统计 |
| 用户满意度 | ≥4.2/5 | 问卷调查 |

## 2. 用户场景

### 2.1 场景一：PRD 写作辅助
> *“我想写一份 RAG 系统的 PRD，但不知道如何描述技术方案部分”*
- 用户上传 RAG 架构文档
- 提问：“请生成 RAG 系统的技术方案章节”
- 系统返回结构化回答并标注引用来源

### 2.2 场景二：面试问题准备
> *“AI 产品岗面试常问哪些 RAG 相关问题？”*
- 系统从知识库中检索高频面试题并生成参考答案

## 3. 功能需求

| 模块 | 功能点 | 优先级 |
|------|--------|--------|
| 文档管理 | 支持 PDF/Markdown/Word 文件上传 | P0 |
| 文档管理 | 自动解析文档结构（标题/段落） | P1 |
| 检索问答 | 自然语言提问获取专业回答 | P0 |
| 检索问答 | 显示答案引用来源和置信度 | P0 |
| 系统设置 | API Key 配置界面 | P1 |

## 4. 非功能需求

- **性能**：90% 的查询响应时间 < 3s
- **安全性**：用户文档仅限个人会话访问
- **可扩展性**：支持后续接入 MCP 协议
